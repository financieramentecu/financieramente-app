### Context

This PR implements a comprehensive architecture refactor to migrate from legacy service-based structure to Feature-Based Architecture (Screaming Architecture). This refactoring improves code organization, maintainability, and follows modern React/Next.js best practices.

### Description

This PR migrates all legacy code from `src/services/` and domain-specific code from `src/lib/` to feature-based modules in `src/features/`. The refactoring includes:

**Architecture Migrations:**
- Migrated all legacy services from src/services/ to their corresponding features
- Migrated auth code from src/lib/auth/ to src/features/auth/lib/
- Migrated email code from src/lib/email/ to src/features/email/lib/
- Migrated currency code from src/lib/currency/ to src/features/admin/currencies/lib/

**Feature Structure Completion:**
- Added missing hooks and schemas to incomplete features
- Created src/features/admin/origins/hooks/use-origins.ts with tests
- Created src/features/pre-liquidacion/lib/pre-liquidacion-schemas.ts with tests
- Added auth schemas and hooks in src/features/auth/

**Type Safety Improvements:**
- Applied `readonly` modifier to immutable fields in all main interfaces
- Configured ESLint to prevent use of `any` type (eslint.config.mjs:35)
- Updated all type definitions across features

**Code Quality:**
- Updated all imports across API routes, components, and hooks to use new feature-based paths
- Formatted code files for consistency
- Updated scripts and e2e tests to use new import paths

**Documentation:**
- Added comprehensive architecture refactor documentation in docs/ARCHITECTURE_REFACTOR_SUMMARY.md
- Added TypeScript readonly conventions guide in docs/TYPESCRIPT_READONLY_CONVENTIONS.md
- Added project constitution in speckit.constitution
- Added Cursor IDE configuration and AI agent skills library
